# SpeakUp — English in action

Университет студенттерінің ағылшын тіліндегі коммуникативтік дағдыларын дамытуға арналған интерактивті сайт. Қазақша интерфейс және B1–B2 деңгейіндегі ағылшынша тапсырмалар.

## Дайын архив

[Сайттың коды мен дайын жинағын жүктеу](https://github.com/kadylet02/meruert/raw/refs/heads/main/downloads/SpeakUp.zip).

## Іске қосу

Node.js 20.19+, 22.12+ немесе 24 LTS және npm қажет. Жоба Node.js 24.19.0 нұсқасында тексерілді.

```sh
cd /workspace/meruert
npm ci
npm run dev
```

Басқа компьютерде жоба орналасқан каталогты пайдаланыңыз. Vite әдепкіде 5173 портын қолданады. Өндірістік нұсқаны жинау:

```sh
npm run build
npm run preview
```

`dist/` каталогын статикалық хостингке жүктеуге болады. Сервер, дерекқор, API кілті немесе сыртқы сурет/қаріп сервистері қажет емес. Барлық иллюстрациялар SVG түрінде, қаріптер жоба ішінде сақталған.

## Мүмкіндіктер

- 6 толық жағдаят: кампуста танысу, білім туралы пікірталас, күнделікті келісімдер, жұмыс сұхбаты, сапар жоспарлау, топтық жобаға хабарлама.
- Сөйлеу, тыңдау, пікірталас және жазылым бойынша сүзгілеу; іздеу; тапсырмаларды сақтау.
- Әр тапсырмада мақсат, екі рөл, үлгі диалог, пайдалы тіркестер және талқылау сұрақтары.
- Үш кезең: дайындық → тәжірибе → рефлексия. Тыңдалымда түсінуді тексеретін сұрақ; жазылымда 80–120 сөз талабы.
- Браузердің Speech Synthesis мүмкіндігі арқылы ағылшынша дыбыстау. Дауыс қолжетімсіз болса, мәтіндік балама берілген.
- Микрофонмен жауап жазып, қайта тыңдау. HTTPS немесе localhost және микрофонға рұқсат қажет. Жазбалар серверге жіберілмейді және тапсырма терезесі жабылғанда жойылады; мәтіндік жауап баламасы бар.
- Бір құрылғыда жұппен рөлдік жұмыс. Қашықтан қоңырау немесе бейнебайланыс қызметі жоқ.
- Жеке профиль, апталық мақсат, орындалған тапсырмалар, жұмсалған уақыт және өзін-өзі бағалау.
- Оқу күнделігін CSV түрінде жүктеу.
- Телефонға бейімделген интерфейс, пернетақтамен басқарылатын диалогтар.

## Деректер және зерттеуде қолдану

Профиль, сақталған тапсырмалар және оқу күнделігі осы браузердегі localStorage-те сақталады. Браузер деректерін тазарту оларды жояды; құрылғылар арасында синхрондау жоқ. CSV экспортында мәтіндік жауаптар да бар: зерттеуде қолданғанда келісім мен деректерді қорғау рәсімдерін сақтаңыз.

«Жоба туралы» бөлімінде диссертацияның тақырыбы мен коммуникативтік тәсілдің қағидалары көрсетілген. Өзін-өзі бағалау ресми CEFR тесті немесе автоматты сөйлеу бағалауы емес. Сайт тиімділік туралы зерттеу нәтижелерін ойдан шығармайды. Эксперимент үшін зерттеу дизайны, бақылау тобы, бастапқы/қорытынды бағалау және келісім бөлек ұйымдастырылады.

Бағалау өлшемдері: сөйлеу еркіндігі, өзара әрекет, сөздік қор, сенімділік (1–5). Уақыт — тапсырма терезесін ашқаннан аяқтағанға дейінгі уақыт, толық минутқа жоғары дөңгелектеледі.

## Тексеру

```sh
npm run build
```

Браузер тесті үшін бірінші терминалда dev серверін қосыңыз. Екінші терминалда:

```sh
npx playwright install chromium
npm run test:e2e
npm run test:audio
```

Жүйеде Chromium орнатылған болса, тест оны автоматты қолданады. Қажет болса `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` арқылы браузер жолын көрсетуге болады. `BASE_URL` арқылы сервер мекенжайын ауыстыруға болады.

## Құрылым

- `src/App.tsx` — беттер, интерактивті тапсырмалар, жазба және прогресс логикасы.
- `src/data/activities.ts` — оқу мазмұны, рөлдер, диалогтар мен сұрақтар.
- `src/components/Illustrations.tsx` — сыртқы ресурстарсыз векторлық иллюстрациялар.
- `src/styles.css` — дизайн және экранға бейімдеу.
- `tests/smoke.mjs` — негізгі студенттік сценарийлердің браузер тесті.
- `tests/audio.mjs` — микрофон жазбасы, рұқсат берілмегендегі балама және сақталған деректерді тексеру.

Технологиялар: React 19, TypeScript, Vite, Lucide, Manrope.
